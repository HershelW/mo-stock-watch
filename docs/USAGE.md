# 使用说明

## 启动

推荐日常使用：

```powershell
.\start-mo-stock-watch.bat
```

也可以双击：

- `start-mo-stock-watch.bat`
- `run-release.bat`

第一次编译会比较慢，之后会复用 `target/` 编译缓存。

截图更新与私有账本维护请使用 [单命令流程](PORTFOLIO_OPS.md)。损坏存档或外部修改冲突会明确报错并禁止覆盖；先修正或恢复备份，不要删除真实存档来绕过错误。

## 持仓维护

1. 点击 `工具` 展开工具栏。
2. 点击 `编辑` 进入编辑模式。
3. 可添加、删除或修改持仓行。
4. 点击 `保存` 写入本地数据文件。
5. 退出编辑后会继续按刷新间隔拉取行情。

持仓字段：

- `代码`：6 位 A 股代码。
- `名称`：显示名称，不影响行情查询。
- `数量`：持仓股数。
- `成本`：成本价。
- `市场`：根据代码自动推断，也可手动选择沪/深/北。

## 交易流水

展开 `工具`，点击 `交易`，选择账户和交易类型后输入日期、代码、数量、成交价和费用。买卖会自动更新持仓、成本、现金和已实现盈亏。

分红、费用、入金和出金使用金额字段。详细口径见 [LEDGER.md](LEDGER.md)。

## 行情刷新

应用会从行情接口拉取数据。正常刷新间隔可在工具栏调整，最小 5 秒。刷新失败时会自动延迟重试，避免频繁请求。

当前行情源顺序：

1. 东方财富
2. 腾讯
3. 新浪

每次刷新会先请求东方财富；如果失败、超时或返回空数据，会自动尝试腾讯；腾讯也失败时再尝试新浪。状态栏会显示本次成功使用的行情源。

为了减少无意义请求，应用只会在工作日交易相关时段请求行情：

- `09:20-11:30`
- `13:00-15:00`

其他时间不会持续请求行情接口，但启动和手动刷新仍会拉取一次数据。程序内置 2026 年交易所休市安排，也可在 `提醒` 面板点击 `从上交所更新`。

行情成功后会写入本地缓存。网络失败时仍可显示上次行情，并在顶部标记数据是否已经过期。

## 提醒、自选和分析

- `提醒`：价格、涨跌幅、今日亏损和高点回撤触发 Windows 通知。
- `自选`：观察未持有股票，不影响资产计算。
- 点击持仓或自选名称：查看今开、最高、最低、成交量、成交额、换手率、市盈率和总市值。
- `分析`：查看资产快照、月度收益、沪深 300 对比、最大回撤和仓位集中度。

## OCR 差异确认

AI 或本地 OCR 完成后不会直接覆盖持仓。先选择目标账户并核对差异，再点击 `确认应用`。

默认保留截图中未出现的持仓。只有确认截图是完整账户持仓时，才勾选 `截图未出现的持仓视为清仓`。

## 自动备份

每次保存持仓前会在 `%APPDATA%\mo-stock-watch\backups\` 创建备份并保留最近 20 份。展开 `工具`，点击 `恢复` 可以恢复上一版或指定版本。

## 数据迁移

持仓和设置在：

```text
%APPDATA%\mo-stock-watch\
```

换电脑时复制这个目录即可。源码目录只负责程序本身，不保存个人持仓。

API Key 保存在由当前 Windows 用户加密的 `credentials.dat` 中。复制到另一台电脑后不能直接解密，需要在新电脑重新填写。

## 常见问题

### 项目目录为什么很大？

大头通常是 `target/`，这是 Rust 编译缓存和构建产物，不是源码。它已被 `.gitignore` 排除，不会上传 GitHub。

清理方式：

```powershell
cargo clean
```

### 行情一直失败怎么办？

先确认网络可以访问东方财富接口。如果只是临时失败，应用会自动重试。若接口字段变化，需要更新 `src/quote.rs`。

### 保存后移动项目会不会丢数据？

不会。数据在 `%APPDATA%\mo-stock-watch\`，不是项目目录。
